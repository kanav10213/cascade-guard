Drop your receipts

Three agents read each receipt, apply the expense policy and write the ledger entry. Cascade Guard checks every hand-off against the receipt itself: the total, the date, the vendor, the policy. A mistake goes back to the agent with the reason; if it is still wrong, the receipt is stopped for a person instead of being posted.
